# CLAUDE.md

Classic (non-block) WordPress theme for Ismael Rehab's photo/video portfolio, built on the FHGR IM5 "Portfolio Starter Theme" boilerplate (HS26). Plain PHP/CSS/JS, no build step, no package manager, no tests, and no local PHP/Node install — PHP can't be linted locally.

Design source: Figma exports in `../../mokups/` (DESKTOP/*.pdf, Mobile/*.png). Colors (decided 15.11.2026, 60-30-10): cream `#fffeec` background, dark `#494a45` text/lines, blue `#1b4a6f` only for actions (Kontakt, Senden, active states), green `#1c7f60` only for category labels/filters; only these four colors — no white, black, red, beige or transparency tints (form errors use a dashed border + «!» icon). Lines only: 3px under the header, above the footer, the homepage intro divider, and form field borders; no arrows in links/buttons. Fonts (self-hosted woff2): Montserrat 300/400/700/900, DM Serif Display regular + italic.

## Deployment — read first

[.vscode/settings.json](.vscode/settings.json) configures the VS Code FTP Deploy extension with `"uploadOnSave": true` to the live Hostpoint server (`remotePath: "/"` maps to `wp-content/themes/<theme>/`). **Every saved file is uploaded to production immediately.** Broken PHP on save means a broken live site, so keep edits syntactically complete.

## Dependencies

- **Carbon Fields** must be active as a plugin — it is not bundled. All content fields (`Container`, `Field`, `carbon_get_*`) depend on it.
- Requires PHP 8+ (union types, `mixed`, `str_contains`).

## Architecture

`functions.php` only `require_once`s each `backend/*/index.php`, in this order: `init`, `helpers`, `nav`, `cpt`, `tax`, `carbonfields`, `getter`, `contact`, `seo`.

### backend/ — functionality
| Folder | Purpose |
|---|---|
| `init/` | Admin cleanup: custom image sizes (`preload`, `xxs`…`xl`), Gutenberg disabled, page editor removed, posts/categories/tags/comments hidden, Customizer/theme editor blocked, SVG uploads allowed. Rarely edited. |
| `helpers/` | Global helpers: `get_media_by_id($id, $size)` → `['title','alt','src','width','height','srcset','type']` or `false`, `get_responsive_media($id, $mobile_id, $size)` → `['desktop','mobile']` (for `partials/picture.php`), `get_menu_by_slug($slug)`, `get_youtube_id($url)`. |
| `nav/` | `register_nav_menus`: `main` (Hauptnavigation), `legals` (Rechtliches). |
| `cpt/` | Custom post types — one `_<slug>.php` per CPT, required inside the `init` hook. `project` (URL `/projekt/…`, ordered via page-attributes `menu_order`). |
| `tax/` | Taxonomies — `project_category` (no public archives; used for tags and the Sammlung filter). |
| `carbonfields/` | Field config, loaded on `carbon_fields_register_fields`. `_globals.php` = theme options (contact, socials, form texts/recipient/sender address, Saison → snow); `_project.php` = project title image (+ optional mobile crop), priority, homepage text + Stammdaten; `_modules.php` = module builder (pages **and** projects) + `render_modules()`. |
| `getter/` | `_globals.php`: `get_globals_contact/socials/form()`. `_project.php`: `get_project_teaser_by_id()`, `get_projects()`, `get_project_categories()`, `get_used_project_categories()`, `get_project_facts()`. |
| `seo/` | `<title>` (`get_document_title_text()`: home = name – tagline, else `Page | name`), meta description + Open Graph (per-page `seo_description`/`seo_image` from `carbonfields/_seo.php`, fallbacks: project highlight text/image, then Globales), JSON-LD `ProfessionalService` on the front page, theme favicon (`frontend/assets/favicon/`) unless a WP site icon is set. |
| `contact/` | AJAX handler `contact_form` (nonce + honeypot) → `wp_mail()` to the configured recipient, `From:` = theme option `form_sender` if set. On failure the `wp_mail_failed` reason is appended to the error message for logged-in admins only. |

### Module system (page builder)
Pages have no editor; content is a Carbon Fields `complex` field `modules` defined in [backend/carbonfields/_modules.php](backend/carbonfields/_modules.php). Adding a module = three touches:
1. `->add_fields('<slug>', '<Label>', [...])` in the complex field.
2. Optional `case '<slug>':` in `render_modules()` to transform data (e.g. image IDs → `get_media_by_id()`).
3. View at `frontend/views/modules/<slug>.php`, reading `$args['data']`, wrapped in `<section data-module="<slug>">`.

`render_modules()` loads `frontend/views/modules/{$module['_type']}`, so the view filename must equal the module slug (the `data-module` attribute uses hyphens, e.g. `hero-image`).

Widths: `text`, `image`, `video`, `reels` and `spacer` have a `width` field (`module_width_field()`: full/two_thirds/half/third); `render_modules()` wraps consecutive non-full modules in `.module-row` (12-column grid, `.module-cell` with `--span`, vertically centred, stacked on mobile with reels kept side by side) and starts a new row when the next one no longer fits.

Admin labels are prefixed and ordered by group: «Inhalt ·» (title, text, image, gallery, carousel, video, reels, spacer, facts), «Seite ·» (intro, hero image, story, Projekte-Übersicht, contact, cta), «Angebot ·» (einstieg, karten, ablauf, kundenstimmen, fragen).

Modules: `intro` (homepage split: sticky greeting + portrait that opens contact, hand-picked projects via association), `hero_image`, `story` (alternating text/image; `render_modules()` counts items across all story modules on the page and sets `flipped` → `.is-flipped`), `title` (title, categories below it, optional `subtitle`, lead; on project pages the lead is Montserrat 20px and `get_project_facts()` is shown beside it as a `dl.facts-table` — `render_modules()` then skips the separate `facts` module; facts are vertically centred next to subtitle/lead), `facts`, `video` (YouTube), `reels` (≤3 vertical, YouTube Shorts or MP4), `text` (aligned with the title, max 65ch; on project pages ≥1025px texts over 600 chars get `.is-long` = two columns over the full width, and the title lead spans the full width at 32px; only full-width texts become two-column or merge into a gallery), `image` (single image), `spacer` (invisible; full width = 48px extra gap via negative margin, in a row = empty cell), `gallery` (multi-select `images` grouped into justified rows in `render_modules()` — a row closes at an aspect-ratio sum of ~3.4 or 4 images, a short remainder joins the last row; `.is-rows` flex rows with `--ratio`, no cropping, one image per line on mobile; a gallery without images is skipped), `carousel` (endless via `setupLoopTrack()` in `main.js`: clones before/after, jumps back a lap after scrolling stops, start position set with scroll-snap paused; centre item full size, neighbours 84 %, outer ones 76 % + blur via `data-distance`), `collection` (all projects + category filter; shown as «Projekte», page slug `/projekte/`; the grid carries `data-pending` and stays `visibility: hidden` on ≥769px until `layoutCollection()` has placed the tiles (CSS fallback after 1.5s) to avoid layout shift; the first three teaser images load eagerly; the filter is closed by default: a sliders icon (`.filter-toggle`, icon `filter`) in the sticky `.collection-tools` toggles `#projekte-filter` (`hidden`, `aria-expanded`); open on desktop = tags left of the icon in the same row with a full-width cream bar (`box-shadow` + `clip-path`), on mobile = an absolutely positioned full-width swipeable band below the title row (`::before` paints the row background); a green dot (`.has-filter`) shows an active category while closed; `?kategorie=` opens it; `.collection-header` is `display: contents` so the tools stick inside the section grid, moving to the top on mobile while the header is hidden; one active category at a time — clicking another switches, clicking the active one or «Alle» resets; order Foto, Video, then alphabetical via `get_used_project_categories()`), `contact` (form block, mobile-only by default, optional image beside it), `cta` (question + Kontakt + link to Sammlung), and for the Angebot page `offer_intro` (collage of up to 3 `images` beside the text on desktop, a flat row of three 3:4 images under the buttons on mobile; second link «Zum Angebot» jumps to `#angebot` = the offers section), `offers` (cards; on mobile an endless centred carousel via `setupLoopTrack()` (`.offers-list.is-loop`, 82vw cards, neighbours scaled 0.92 + blurred, clones hidden ≥769px; clicks on «Anfragen» in a side card only centre it); `#angebot` scroll-margin accounts for the `scroll-padding-top` on `html` and the hidden mobile header; `occasion` preselects the form field via `data-occasion`), `process` (full-width blue band, `id="ablauf"`; phases → nested complex `steps` with title/addition/text, numbered 01… across phases), `testimonials`, `faq` (`<details>`). `get_collection_url()` (Globales → Seiten, else first page containing the `collection` module) feeds the intro CTA and the active menu item on project pages. A short `text` (≤600 chars) directly before a `gallery` with `images` is skipped in `render_modules()` and rendered as the first tile of the gallery’s first row (`.gallery-text`, ratio = length/270 clamped 1.3–2.2, vertically centred, max 60ch). All body texts in `main` (p, li, FAQ answers) are justified with `hyphens: auto`, except titles/labels/buttons/centred lines listed in the `:not()` of that rule. A custom dot cursor (`.cursor`, `html.has-cursor`) is added in `main.js` for fine pointers only; it becomes an 18px ring over interactive elements, and the native cursor returns in form fields and while a dialog is open. Project pages have no back link; categories sit under the title; at the bottom «Andere Projekte» (`partials/more-projects.php` with `get_other_projects()`, starting with the next project; the Angebot page shows the same band titled «Projekte» with all projects via `page_has_module('offers')` in `pages/page.php`; tiles 56vw on mobile, without the name pill) is an endless band using the same `setupLoopTrack()` — click a side tile to centre it, click the centre tile to open it; outer tiles blurred, name pill on hover (always on the centre tile without hover).

Project teasers: each project has one plain title image (field `highlight_image`, label «Titelbild») plus an optional `teaser_video` (MP4; `partials/teaser-video.php` lays it over the image in both tiles, muted loop with the title image as poster; `observeTeaserVideos()` in `main.js` plays it only while visible, off with reduced motion / save-data, and is also called for marquee clones); the Sammlung shows it with the category label and reveals the title in a blue box on hover (desktop only); its grid span (1 or 2 of 3 columns) is chosen in `main.js` with a seeded pseudo-random per project ID unless `teaser_size` forces narrow/wide. The Sammlung grid has 12 columns; `layoutCollection()` in `main.js` builds rows of 2–4 projects from `rowPatterns`, reshuffled per visit (seeded once per page load), and gives high-priority projects (`teaser_size`: wide = high, narrow = low) the widest slot. Homepage desktop shows `highlight_image` + title + text; mobile (<768px) shows only images (4:5) with the category label, title/text visually hidden, plus an «Alle Projekte ansehen» button.

Mobile-only extras: `.page-cta` (rendered before the footer, hidden when `main` already contains a `.cta` or contact module) and the project title image in the `title` module. Lightbox (`views/layout/lightbox.php`, desktop and mobile): gallery, single `image` and carousel images on project pages open full size; desktop has «Zurück»/«Weiter» text buttons (no arrows), arrow keys and a counter, loops at the end, click on the dark area closes; mobile swipes (counter only); in the carousel only the centre item opens it on desktop. Homepage typing animation: an inline script in `header.php` sets `html.is-typing` on the first visit per session (`sessionStorage`, off with reduced motion); `main.js` splits the intro heading into `.char` spans and reveals them one by one (switching to `is-typing-js`; per-part speed in `speeds`, the name slower), including the subtitle; CSS fallback shows the heading after 3s if the script fails. New image sub-sizes are saved as WebP (`image_editor_output_format` in `init/`), and the homepage portrait is preloaded (`seo/`).

### Templates
Root WP templates (`index.php` = 404 page with a joke headline, button to the projects and the project band, `page.php`, `single-project.php`) are thin: `get_header()` → `frontend/views/layout/header` → `frontend/views/pages/<x>` → `frontend/views/layout/footer` → `get_footer()`. Root `header.php`/`footer.php` hold the HTML shell and load `frontend/styles/main.css` and `frontend/scripts/main.js` (ES module) directly — no `wp_enqueue_*`; both are cache-busted with the theme version from `style.css`. `footer.php` also renders the contact `<dialog>` (`views/layout/contact.php`); any element with `data-contact-open` opens it (delegated click listener, so cloned elements work too). Contact words: theme option `contact_words` (Globales → Kontaktformular, default «Kaffee?, Portrait?, Hochzeit?, Event?, Film?») is output as `data-contact-words` on `<body>`; on hover devices `main.js` makes `.button-contact[data-contact-open]` cycle «Kontakt» → words (`.word-swap`, all words stacked so the width stays; original text as `aria-label`), and the homepage portrait label shows the words instead of `portrait_hover` (cycling on hover, automatically on touch), and every `.contact-title` (dialog and contact module) cycles through the words automatically while visible (IntersectionObserver, `.word-swap.is-start`, original `form_title` kept as visually-hidden text; off with reduced motion). The form shows `form_note` (Globales → Kontaktformular, default «… melde mich innerhalb der nächsten 48 Stunden …») above the submit button; the nonce is a plain hidden input without id because the form can appear twice on a page. `header.php` starts `<body>` with a skip link to `#inhalt` (every `<main>` has `id="inhalt" tabindex="-1"`). The form has a hidden input named `action`, which shadows `form.action` in JS — `main.js` reads the URL with `getAttribute('action')`. After adding a `single-<cpt>.php`, permalinks must be re-saved in WP admin.

### frontend/
- `views/layout|pages|modules|teaser|partials/` — markup. `partials/` holds reusable bits: `picture`, `image`, `facts`, `contact-form`, `icon`.
- `styles/main.css` — imports `_fonts.css` and `_resets.css`; design tokens as custom properties in `:root` — use only these: spacing `--space-1`…`--space-8` (8/16/24/32/48/64/96/128), radii `--radius-s` 6px (buttons, labels, fields) / `--radius-l` 20px (images, cards), font sizes `--text-xs`…`--text-3xl` (14/16/20/24/32/48/88); components are selected via data attributes (`[data-layout]`, `[data-page]`, `[data-module="..."]`) with native CSS nesting; desktop-first `max-width` breakpoints (3xl 1514 → xxs 400) at the bottom.
- `assets/fonts/` — self-hosted woff2, declared in `_fonts.css`.

### Motion
The «Bewegung» block in `main.css` + end of `main.js`: scroll reveals (`main.js` adds `.reveal` only to elements below the fold, IntersectionObserver adds `.is-visible`, classes are removed again after 2s; easing `--ease-glide`, 48px travel), cross-document view transitions (`@view-transition` with type `seitenwechsel`; root fade/slide only under `:active-view-transition-type(seitenwechsel)` ; the Sammlung filter does not use view transitions — `animateFilter()` fades the grid out (`.is-filtering`), re-lays it out and glides the visible tiles in with a stagger (`.is-entering`, `--enter-delay`); no static names on tiles — a `pageswap` handler in `main.js` names only the clicked, visible tile picture `project-image`, matching the project title image), sliding nav highlight and mobile menu, soft FAQ (`::details-content`), hero parallax (`animation-timeline: view()`), mobile header hides on scroll down (`.is-hidden`). Homepage desktop (>768px): `main.js` moves the project highlights into `.intro-marquee-track` with clones (aria-hidden, no transition names) and scrolls it endlessly at 35px/s (`.is-marquee`; pause on hover/focus, mouse wheel moves it, CTA/all-projects button hidden there; «Fotos · Videos» (`.intro-categories`, `category_links` from `render_modules()`: Projekte-Übersicht with `?kategorie=foto|video`, only for used categories) sits above the portrait on all widths); reverts to a normal list on mobile. Seasonal snow: theme option `snow` (Globales → Saison) renders `<canvas class="snow">` in `footer.php`; `main.js` draws ≤45 slow cream flakes with a faint dark glow (fixed, z-index 90 below the header, `pointer-events: none`). All off with `prefers-reduced-motion`. Headless Chrome with `--virtual-time-budget` does not run IntersectionObserver/scroll events — test motion in real time.

## Conventions
- Code comments and admin labels are in **German**; comments use the `// -> description` style, `// todo:` for placeholders.
- Field, module, CPT and taxonomy slugs are `snake_case`; partial files in backend subfolders are `_`-prefixed and required from that folder's `index.php`.
- Keep data fetching in getters/`render_modules()`; views should only output.

## WordPress setup the theme expects
- Pages: Startseite (set as static front page, module `intro`), Über mich, Sammlung (module `collection`), Impressum, Datenschutz, AGB.
- Menus: `main` (über mich, Sammlung), `legals` (Impressum, Datenschutz, AGB).
- After changing CPT/taxonomy registration: re-save Settings → Permalinks.
- Mail delivery depends on the host's `wp_mail()`; an SMTP plugin may be needed.
